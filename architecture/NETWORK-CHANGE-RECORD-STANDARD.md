# PAL Network Change Record Standard

## Change metadata

- Change ID
- Date/time/timezone
- Operator
- Systems/interfaces affected
- Business/lab objective
- Risk classification

## Pre-change evidence

- current configuration export
- screenshots/commands
- link and route state
- recovery path

## Implementation

- exact ordered steps
- expected impact
- stop conditions

## Validation

- positive tests
- negative tests
- monitoring/log review
- reboot/persistence test where appropriate

## Rollback

- exact reversal steps
- required console/backup
- maximum tolerated outage

## Closure

- result
- evidence filenames
- unresolved issues
- documentation updates
- Git commit hash
