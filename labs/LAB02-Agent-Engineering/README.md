# Lab 02 - Agent Engineering Environment

## Objective

Define the roles, boundaries, strengths, and weaknesses of:

* ChatGPT
* Codex
* Claude Code
* Hermes

inside the PADRO-AI-LABS ecosystem.

## Questions

1. What is each agent best at?
2. What tasks should be delegated to each agent?
3. Where should human review remain mandatory?
4. What security controls should govern agent actions?
5. How should agent-generated work be documented?

## Desired Outcome

A documented agent orchestration model suitable for future AI engineering, OSINT, GRC, DFIR, and automation projects.
