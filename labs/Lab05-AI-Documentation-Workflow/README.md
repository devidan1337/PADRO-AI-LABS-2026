# Lab05 — AI Documentation Workflow

## Purpose
Build a repeatable workflow that turns hands-on technical work into structured documentation, lessons learned, portfolio artifacts, and future AI-retrievable knowledge.

## Goal
Create a system where each technical action can become:

- a Git commit
- a lab report
- a reusable lesson
- a portfolio-ready artifact
