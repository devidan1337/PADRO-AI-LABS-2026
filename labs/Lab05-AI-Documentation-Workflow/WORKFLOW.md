# Lab05 Workflow — AI Documentation Pipeline

## Workflow Pattern

Technical Work
→ Capture Notes
→ Summarize Decision
→ Extract Lesson
→ Update Program Brain
→ Commit to Git
→ Convert to Portfolio Artifact

## Step 1 — Capture the Work
Record what happened immediately after doing the work.

Capture:
- command used
- problem encountered
- fix applied
- result
- lesson learned

## Step 2 — Classify the Note
Each note should belong to one or more categories:

- Architecture
- Standards
- Lessons Learned
- Operations
- Security
- Career Evidence
- Portfolio Artifact

## Step 3 — Update Command Center
Update one of the five command-center files when relevant:

- PADRO-AI-LABS.md
- CURRENT-ROADMAP.md
- CURRENT-ARCHITECTURE.md
- CURRENT-STANDARDS.md
- HIGH-VALUE-LESSONS.md

## Step 4 — Commit the Work
Use this pattern:

git status
git diff
git add .
git commit -m "Clear milestone message"
git push

## Step 5 — Convert to Artifact
When a lab is complete, convert the work into:

- lab report
- blog draft
- diagram
- video outline
- resume bullet
- portfolio page
