# Lab07 Lessons — Telecom Automation Foundation

## Lesson 1

Start automation with low-risk, local, read-only tasks.

## Lesson 2

Operational automation should produce evidence, not just output.

## Lesson 3

A useful script becomes more valuable when paired with documentation, use cases, and reporting.

## Lesson 4

Telecom automation should respect human approval boundaries before touching live systems.

## Lesson 5

The safest path is to automate observation before automating action.
