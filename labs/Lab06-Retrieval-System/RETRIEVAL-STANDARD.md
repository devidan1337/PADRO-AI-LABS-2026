# Retrieval Standard

## Core Principle
Every important note should be easy to find by title, folder, keyword, tag, and relationship.

## Naming Standard
Use clear filenames that describe the subject directly.

Good:
- WSL-OBSIDIAN-WATCHER-ISSUE.md
- HERMES-MEMORY-ARCHITECTURE.md
- LAB05-AI-DOCUMENTATION-WORKFLOW.md

Avoid:
- notes.md
- stuff.md
- ideas.md

## Required Retrieval Fields
For major notes, include:

- Title
- Date
- Category
- Tags
- Related Files
- Summary
- Decision / Lesson / Output

## Link Standard
Use Obsidian links when connecting major concepts.

Example:
[[CURRENT-ARCHITECTURE]]
[[HIGH-VALUE-LESSONS]]
[[PROGRAM-BRAIN-ARCHITECTURE]]
