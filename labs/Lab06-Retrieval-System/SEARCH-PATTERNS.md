# Search Patterns

## Human Search
Use filenames, folders, and grep.

Examples:
grep -R "Obsidian" .
grep -R "Hermes" .
grep -R "retrieval" .

## Obsidian Search
Search by:
- exact filename
- tag
- phrase
- linked note

## Git Search
Use Git history to find when a decision was made.

Examples:
git log --oneline --all --grep="Obsidian"
git log --oneline --all --grep="Program Brain"
git diff HEAD~1 HEAD

## Future AI/RAG Search
Future retrieval systems should prioritize:
- command-center files
- lab reports
- architecture files
- lessons learned
- security standards
