# High Value Lessons

## Repository Governance

Maintain one authoritative repository.

## Security

Secrets represent authority.

## Architecture

Architecture before implementation.

## Automation

Governance before automation.

## Knowledge

Nothing enters Program Brain unless it is safe to retrieve later out of context.

## Documentation

Document decisions, not just outcomes.

## AI

Capability and authority are not the same thing.

## Recovery

A system that cannot be rebuilt is not truly understood.
