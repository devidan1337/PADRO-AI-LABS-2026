# CURRENT STANDARDS

## Git Standard
- Work from repository root.
- Run git status before commits.
- Use clear commit messages.
- Commit meaningful milestones, not random noise.

## Documentation Standard
- Every major lab gets a report.
- Every major decision gets recorded.
- Every repeated issue becomes a lesson.
- Every architecture change updates CURRENT-ARCHITECTURE.md.

## Obsidian Standard
- Repository root is the vault.
- Command-center files live at root.
- Use links between roadmap, architecture, lessons, labs, and reports.

## Security Standard
- Do not commit secrets.
- Document security assumptions.
- Keep automation safe, testable, and reversible.
